# Дебат Йотова – Гюров, БНТ, 29.10.2026 — структуриран препис

Структуриран, атрибутиран и възпроизводим текст на президентския дебат между
Илияна Йотова и Андрей Гюров (БНТ, 29.10.2026), изграден върху машинен препис
(Whisper large-v3) без диаризация.

```bash
make all     # проверка → build/debate.xml → .md → .html → build/debate.pdf
```

| Артефакт | Описание |
| --- | --- |
| `build/debate.xml` | каноничният структуриран текст (валидиран по `schema/debate.xsd`): атрибуция, време, прекъсвания, четим текст + дословен изход в `<source>` |
| `build/debate.md` | Markdown рендиране |
| `build/debate.html` | HTML за печат (шаблон за PDF) |
| `build/debate.pdf` | A4 PDF с корица, типография, вътрешни връзки и bookmarks |
| `build/overview.pdf` | кратък обзор: структура, аргументи по теми, кой колко говори, намеси на водещата |
| `data/attribution/` | ръчно проверената атрибуция на говорителите |
| `data/corrections.yml` | корекции, неясни места, двусмислия, пропуски |
